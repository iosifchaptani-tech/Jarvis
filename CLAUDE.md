# How to help the owner of this project

- The owner isn't technical. They use Windows and have Claude Code in PowerShell on their PC.
- If Claude Code on their PC could do a task itself (downloading, installing, running,
  testing, fixing files), don't give step-by-step instructions. Give one short prompt
  they can copy: "Open PowerShell, type `claude`, press ENTER, then paste this:"
  followed by the prompt in a code block.
- Only give manual steps for things Claude Code can't do: logging in to websites,
  payments, creating API keys, and talking into the microphone.
- Keep answers short and simple. Never ask them to paste API keys into a chat.
